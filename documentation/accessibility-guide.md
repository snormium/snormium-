# Accessibility
Works from the installer onward (installer: press the a11y icon or Super+Alt+S for Orca).
System Settings ▸ **Accessibility**: screen reader (Orca, Super+Alt+S), magnifier (Alt+Super+8, zoom Alt+Super+=/−), high
contrast, large text, visual alerts, sticky/slow/bounce keys, mouse keys, on-screen keyboard (Onboard, also on the login screen),
speech via `speech-dispatcher` (espeak-ng). Braille displays via `brltty` (started automatically when detected).
The Welcome, Security and Recovery centers are plain GTK apps: fully keyboard-navigable and Orca-readable.
