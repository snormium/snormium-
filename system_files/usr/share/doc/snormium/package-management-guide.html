Package management

Snormium is image-based: the system is one signed image that updates atomically; apps come from Flathub via Discover. * Discover installs Flatpak apps and shows firmware and system-image updates in one place. * Need a command-line tool or something not on Flathub? brew install <tool> (Homebrew is built in) or a Distrobox container (ujust distrobox) — neither touches the system image. * Layering RPMs onto the image (rpm-ostree install) works but slows updates; prefer the options above. * No PPAs, no curl-pipe installers. Emulators that exist only as AppImages are fetched with pinned checksums (snormium-app-fetch), never blindly.
