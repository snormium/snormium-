First start

The Welcome Center opens automatically. Do these two things first: 1. Update your computer — installs today's fixes. Automatic updates are already on. 2. Install drivers — only if it lists a recommended driver (NVIDIA, some Wi-Fi, Broadcom). Then look at Security Center; a green banner means you're done. Everything else in Welcome is optional. Untick Show this window at every login when you no longer need it (System menu ▸ Welcome Center brings it back).
